HDLF HANA Data Lake Files
HDLF (HANA Data Lake Files)
Object store de Datasphere donde vive el data lake — el archivo físico (Parquet/Delta) que materializan Transformation Flow y Replication Flow, fuera del motor HANA.
Delta Tables
Delta Tables
Se construye SOBRE los Parquet Files agregando transaction log (versionado transaccional) — mismo archivo físico, con metadata adicional. Puede replicarse de vuelta a HANA vía Replication Flow, o compartirse externamente.
▲
Parquet Files
Parquet Files
Archivo físico columnar que Transformation Flow materializa en el data lake (HDLF) — la base sobre la que se construye la Delta Table.
⬛🔲⬜ Bronze / Silver / Gold
⚠️ A diferencia de la ingesta en HANA DB, en HDLF la "tabla" es un archivo físico: Transformation Flow lo materializa como Parquet, y la Delta Table se construye sobre ese Parquet agregando transaction log. Replication Flow puede devolver la Delta Table a HANA si hace falta. El ciclo de vida del dato es responsabilidad del flujo que lo crea.
ZCDS_DWC_DIM_TEMPLATE se sugiere como extractor integral de dimensión maestra (sea atributo, texto o conjuntamente). La diferenciación de CDS por atributos y texto pierde sentido en el marco de core data services puesto que la anotación dataCategory: #TEXT no es compatible con extracción sino como capa intermedia para asociaciones de texto desde otras CDS en S/4.
