SQL Server 3
SQL Server (no-SAP)
Compatible con Tablas Remotas: conexión directa vía ODBC/SDA hacia Datasphere (acceso federado, sin replicar).
Azure 4
Azure (no-SAP, sin tabla remota)
Sin compatibilidad de federación directa: ingesta vía Data Flows / Replication Flows hacia Tablas locales (persistencia necesaria).
